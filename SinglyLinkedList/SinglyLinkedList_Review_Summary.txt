[2] InsertAtPosition.c (Question 25)
    Status: REVIEWED (Unique Positional Insertion)
    Category: 1-Based Indexing & Predecessor Splicing
    Problem Statement:
      Insert a node at an arbitrary 1-based index position with full boundary 
      checking.
    Key Algorithmic Concepts:
      - Distinguishes head insertion (pos == 1) from intermediate/tail insertion.
      - Traverses to predecessor node at (pos - 1).
      - Catches invalid out-of-bounds positions (pos < 1 or pos > length + 1).
      - Safely splices: newNode->next = curr->next; curr->next = newNode.

[4] ReverseSinglyLinkedList.c (Question 29)
    Status: REVIEWED (Unique Canonical Algorithm)
    Category: In-Place Iterative Pointer Reversal
    Problem Statement:
      Reverse a singly linked list in-place in O(N) time and O(1) auxiliary space.
    Key Algorithmic Concepts:
      - Three-pointer sliding window: prev (NULL), curr (head), and next (NULL).
      - Pointer inversion sequence:
          next = curr->next;
          curr->next = prev;
          prev = curr;
          curr = next;
      - Finally updates *head = prev.
      - Canonical building block for complex list transformations.

[5] MiddleNode.c (Question 30)
    Status: REVIEWED (Unique Two-Pointer Technique)
    Category: Fast & Slow Pointer (Tortoise and Hare)
    Problem Statement:
      Find the middle node of a singly linked list in a single traversal.
    Key Algorithmic Concepts:
      - Slow pointer advances 1 step (slow = slow->next).
      - Fast pointer advances 2 steps (fast = fast->next->next).
      - When fast hits the end, slow is precisely at the midpoint.
      - Handles odd vs even node count conventions (first vs second middle).

--------------------------------------------------------------------------------

[6] KthFromEnd.c (Question 31)
    Status: REVIEWED (Unique Two-Pointer Technique)
    Category: Fixed Offset / Delay Window Technique
    Problem Statement:
      Find the k-th node from the end of a singly linked list in a single pass.
    Key Algorithmic Concepts:
      - Uses two pointers (ref_ptr and main_ptr) separated by a fixed gap of k.
      - ref_ptr is first advanced k steps from the head.
      - If list length < k, returns an error immediately.
      - Both pointers advance together; when ref_ptr hits NULL, main_ptr points 
        to the k-th node from the end.
      - Avoids two-pass length computation.

--------------------------------------------------------------------------------

[7] RemoveDuplicates.c (Question 32)
    Status: REVIEWED (Unique In-Place Deduplication)
    Category: Runner Pointer Technique (Unsorted List)
    Problem Statement:
      Remove duplicate values from an unsorted singly linked list without extra space.
    Key Algorithmic Concepts:
      - Employs a nested two-pointer "runner" traversal: for every node curr, 
        an inner runner pointer scans curr->next to NULL.
      - If runner->data == curr->data, unlinks the node and frees memory immediately.
      - Runs in O(N^2) time and O(1) space, avoiding hash set dependencies.

[11] SplitList.c (Question 39)
     Status: REVIEWED (Unique Destructive Partitioning)
     Category: Midpoint Bisection & Link Termination
     Problem Statement:
       Split a linked list into two balanced sublists using slow and fast pointers.
     Key Algorithmic Concepts:
       - Uses fast pointer initialized at source->next and slow at source.
       - When fast reaches end, slow sits at the end of the first half.
       - Performs link termination: slow->next = NULL, producing two clean lists.
       - Essential partition step for Linked List Merge Sort.

[12] CycleDetection.c (Question 40)
     Status: REVIEWED (Unique Algorithmic & Mathematical Benchmark)
     Category: Floyd's Cycle Finding Algorithm (Detection & Entry Node)
     Problem Statement:
       Detect if a cycle exists in a singly linked list, and if so, determine 
       the exact node where the cycle begins.
     Key Algorithmic Concepts:
       - Phase 1: fast moves 2 steps, slow moves 1 step. Meeting confirms a cycle.
       - Phase 2: reset ptr1 to head, keep ptr2 at meeting point. Advance both 
         at 1 step per cycle. They meet at the cycle entry node.
       - Mathematical derivation: L1 = nC - k.
